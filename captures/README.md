# captures/

Empty on purpose until capture #1.

Name directories:

```
YYYYMMDD_<model>_<fw>_<scenario>/
```

Examples:

```
20260922_pch1000_fw365_coldinsert/
20260922_pch2000_fw365_sleepwake/
```

Each directory **must** contain `notes.json` (copy `_template/notes.json`) plus the trace file(s).
